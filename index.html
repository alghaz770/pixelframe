Ubah videomu

Unggah sebuah video, atur pilihannya, lalu proses menjadi video ASCII. Semua langkah — termasuk menyusun berkas MP4-nya — berjalan langsung di peramban memakai WebCodecs API; videomu tidak pernah dikirim ke server mana pun.

Browser ini tampaknya tidak mendukung WebCodecs API (VideoEncoder) yang dibutuhkan untuk menyusun video. Coba gunakan versi terbaru Chrome, Edge, atau Safari.

Cara kerja

Tiga tahap, semuanya terjadi di dalam peramban, tanpa mengunggah videomu ke server mana pun.

Video dijeda pada interval waktu tertentu sesuai frame per detik yang kamu pilih, lalu tiap frame dibaca kisi kecerahannya.
Tiap frame diubah jadi kisi karakter — sel gelap jadi karakter padat, sel terang jadi karakter jarang — memakai set karakter dan mode warna pilihanmu.
Frame-frame karakter disandikan langsung jadi video H.264 dan disusun ke dalam berkas MP4 oleh peramban sendiri — siap diunduh dan dibagikan.
PixelFrame — dari keluarga PixelGlyph, untuk mengubah video menjadi tipografi bergerak. Berjalan sepenuhnya di perangkatmu, memakai WebCodecs API bawaan browser.
